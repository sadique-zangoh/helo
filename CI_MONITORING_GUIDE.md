# CI Monitoring Guide

## Overview
This project now has comprehensive CI/CD monitoring infrastructure in place.

## Components

### 1. GitHub Actions Workflow (`.github/workflows/ci.yml`)
Automated CI pipeline that runs on every push and pull request.

**Jobs:**
- **test**: Runs tests across Python 3.10, 3.11, and 3.12
  - Installs dependencies with uv
  - Runs pre-commit hooks
  - Executes pytest with coverage
  - Uploads coverage to Codecov

- **lint**: Enforces code quality standards
  - ruff (linting and formatting)
  - black (code formatting)
  - isort (import sorting)
  - mypy (type checking)

- **security**: Security scanning
  - bandit (security issues)
  - safety (dependency vulnerabilities)

### 2. CI Monitoring Script (`.github/scripts/check_ci.sh`)
Interactive script to check CI status from command line.

**Usage:**
```bash
# Basic usage (limited API access)
./.github/scripts/check_ci.sh

# With authentication (full access)
GITHUB_TOKEN=your_token ./.github/scripts/check_ci.sh
```

**Features:**
- Shows latest workflow runs for current branch
- Displays status and conclusion for each run
- Provides direct links to workflow runs
- Clear status indicators (✅ ❌ 🔄 ⚠️)

### 3. CI Status via API

You can also check CI status programmatically:

```bash
# Get latest runs
curl -H "Authorization: token $GITHUB_TOKEN" \
  "https://api.github.com/repos/sadique-zangoh/helo/actions/runs?per_page=5"

# Check specific workflow
curl -H "Authorization: token $GITHUB_TOKEN" \
  "https://api.github.com/repos/sadique-zangoh/helo/actions/workflows/ci.yml/runs"
```

## Troubleshooting

### No CI runs showing up
- Workflow file hasn't been pushed yet
- Branch hasn't been pushed to remote
- Workflow triggers don't match your branch pattern

### CI failing
- Check logs in GitHub Actions tab
- Run checks locally: `pre-commit run --all-files`
- Run tests locally: `pytest`
- Check linting: `ruff check .`

### API rate limiting
- Set GITHUB_TOKEN environment variable
- Use authenticated requests for higher rate limits
